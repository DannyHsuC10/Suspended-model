# Natural_frequency

This folder is split into independent MATLAB mini-projects. Each project has its own script, `data.csv`, `load_data.m`, and markdown note.

## Projects

- `aero_spring`: pitch stiffness requirement from acceleration and allowable pitch angle.
- `Maximum_compression`: pitch and roll stiffness requirements from allowable suspension compression.
- `Overall_rigidity`: equivalent stiffness from tire, suspension, and chassis stiffness in series.
- `PSD`: ISO road profile and excitation frequency energy analysis. Its speed trace is stored at `PSD/vt_data.xlsx`.
- `Tire_Ring_Structural_Mode`: tire ring structural mode frequency estimate.

Run the `.m` file inside each project folder. Parameters are stored in that project's own `data.csv`.
