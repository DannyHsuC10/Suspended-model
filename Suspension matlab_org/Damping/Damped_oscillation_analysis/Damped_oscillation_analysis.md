# Damped_oscillation_analysis

This project compares quarter-car responses across damping ratios.

## Outputs

- Sprung displacement over time
- Dynamic tire load variation over time

## Files

- `Damped_oscillation_analysis.m`: main MATLAB script.
- `data.csv`: parameters for this script only.
- `load_data.m`: CSV loader.

Run `Damped_oscillation_analysis.m` in MATLAB. Parameters can be changed from `data.csv`.
