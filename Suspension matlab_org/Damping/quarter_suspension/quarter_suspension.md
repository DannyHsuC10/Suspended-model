# quarter_suspension

This project simulates a damped quarter-car model with a road step input.

## Outputs

- Sprung and unsprung displacement
- Sprung and unsprung velocity
- Sprung and unsprung acceleration
- Total energy response

## Files

- `quarter_suspension.m`: main MATLAB script.
- `data.csv`: parameters for this script only.
- `load_data.m`: CSV loader.

Run `quarter_suspension.m` in MATLAB. Parameters can be changed from `data.csv`.
