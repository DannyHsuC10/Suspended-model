## 一、 剛性組合與幾何計算 (Stiffness & Geometry)

在計算車身變形前，必須先將「懸吊彈簧」與「輪胎剛性」進行串聯與轉換。

### 1. 輪胎等效側傾剛性 ($k_{rollt}$)

輪胎本身形同一個線性彈簧（剛性為 $k_{tire}$）。當車身發生側傾時，兩側輪胎一邊壓縮、一邊拉伸。利用輪距 $t$，將輪胎的線性剛性轉換為扭轉剛性（扭矩/弧度）：


$$k_{rollt, rad} = \frac{k_{tire} \times t^2}{2} \quad (N\cdot m / rad)$$


程式碼中隨即使用 `np.deg2rad` 轉換，實質上將單位變成了 $N\cdot m / deg$。

### 2. 彈簧串聯 (Series Springs)

車身底盤與地面之間有兩層彈簧：**底盤懸吊彈簧**與**輪胎**。物理上它們屬於**串聯（Series）關係**，總剛性會變小。

* **總側傾剛性 ($k_{roll}$)**：懸吊側傾剛性 ($k_{rolls}$) 與輪胎等效側傾剛性 ($k_{rollt}$) 串聯。

$$\frac{1}{k_{roll}} = \frac{1}{k_{rolls}} + \frac{1}{k_{rollt}} \implies k_{roll} = \frac{k_{rolls} \times k_{rollt}}{k_{rolls} + k_{rollt}}$$


* **前後軸等效上下跳動剛性 ($k_{heave\_f}, k_{heave\_r}$)**：

$$k_{heave} = \frac{k_{suspension} \times k_{tire}}{k_{suspension} + k_{tire}}$$



### 3. 俯仰中心 (Pitch Center) 與俯仰剛性 ($k_{pitch}$)

模型利用前後軸垂直剛性的比例，找出車身的俯仰中心位置（離前後軸的距離 $l_{pcf}$ 與 $l_{pcr}$）：


$$l_{pcf} = l \times \frac{k_{heave\_r}}{k_{heave\_f} + k_{heave\_r}}$$


找出中心後，再將前後軸的垂直剛性乘以力臂平方，加總轉換為整車的**俯仰扭轉剛性 ($k_{pitch}$)**：


$$k_{pitch} = k_{heave\_f} \times l_{pcf}^2 + k_{heave\_r} \times l_{pcr}^2 \quad (N\cdot m / deg)$$

## 二、 車身姿態改變量 (Vehicle Attitude $dh_a$)

當車輛受到加速度時，慣性力會通過重心（CG）對應的力臂產生力矩，使車身旋轉。

### 1. 側傾角計算 (`roll_angle`)

當受到側向加速度 $a_y$ 時，力臂為重心高度減去側傾中心高度（$h_{cg} - h_{roll}$）。


$$\theta_{roll} = -\frac{m \times a_y \times (h_{cg} - h_{roll})}{k_{roll}} \times \text{CG\_rate}$$

> *註：程式碼中乘以 `CG_rate` 分配前後軸，並額外除以 $h_{cg}$ 的修正項，是用來逼近懸吊幾何力矩分配的簡化算式。*

### 2. 俯仰角計算 (`pitch_angle`)

當受到縱向加速度 $a_x$ 時（如煞車 $a_x < 0$ 導致車頭下沉）：


$$\theta_{pitch} = -\frac{m \times a_x \times (h_{cg} - h_{roll})}{k_{pitch}}$$

### 3. 姿態幾何投影 (`attitude_dh`)

計算出角度 $\theta_{roll}$ 與 $\theta_{pitch}$ 後，利用前翼與輪胎相對車體中心的幾何力臂（`P_ay` 與 `P_ax`），將**角度旋轉**轉換為車身四個角落的**垂直位移量 $dh_{roll}$ 與 $dh_{pitch}$**。


$$\Delta h_{attitude} = dh_{pitch} + dh_{roll}$$

## 三、 空氣動力學下壓位移 (Aerodynamic $dh_v$)

車輛在高速行駛時，空氣動力會產生垂直下壓力。

1. **計算總下壓力 ($F_{downforce}$)**：

$$F = C_{air} \times v^2 = \left(\frac{1}{2} \rho C_l A\right) \times v^2$$


2. **依據壓力中心 (COP) 分配前後軸下壓力**：
* 前軸下壓力：$F_f = F \times \text{COP}[0]$
* 後軸下壓力：$F_r = F \times \text{COP}[1]$


3. **計算由下壓力引起的懸吊下沉量 ($dh_v$)**：

$$dh_f = \frac{F_f}{k_{heave\_f}}, \quad dh_r = \frac{F_r}{k_{heave\_r}}$$



---

## 四、 最終前翼高度整合 (`aero_data`)

最後，核心函式 `aero_data` 將上述所有動態效能整合。前翼的最終離地高度等於：

$$\text{最終高度 } h_f = \text{初始靜態高度 } (h_{fw}) - \text{動態慣性位移 } (dh_a) - \text{空力下壓位移 } (dh_v)$$

### 計算流程總覽

```
輸入參數: 速度 (v), 縱向加速度 (ax), 側向加速度 (ay)
  │
  ├───► 1. 計算空氣動力 ──► 產生垂直下沉量 (dh_v)
  │
  └───► 2. 計算慣性力矩 ──► 產生俯仰與側傾角 ──► 投影為幾何位移 (dh_a)
  │
  ▼
綜合疊加: h = h_fw - dh_a - dh_v ──► 輸出前左/前右翼的最終離地高度 (hf)

```

透過這個模型，賽車工程師可以在不進行完整全車 CFD 或實車軌道測試的情況下，快速評估車輛在過彎煞車時，前翼是否有觸底（Bottoming out, $h \le 0$）的危險，以此作為彈簧剛性調整與空力套件設計的依據。
