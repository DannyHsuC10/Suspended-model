# spring

This folder is split into independent MATLAB mini-projects. Each project has its own script, `data.csv`, `load_data.m`, and markdown note.

## Projects

- `ride_rate`: ride rate from spring rate, motion ratio, and tire stiffness.
- `Spring_stiffness`: spring stiffness sweep and natural frequency.
- `Suspension_Oscillation`: analytical vs Explicit Euler undamped oscillation.
- `Time_sensitivity_analysis`: Euler time-step sensitivity and energy error.
- `Tire_suspension_spring`: undamped coupled quarter-car tire/suspension ODE.
- `Unsprung_mass`: unsprung mass sweep and wheel-hop frequency.

Run the `.m` file inside each project folder. Parameters are stored in that project's own `data.csv`.
