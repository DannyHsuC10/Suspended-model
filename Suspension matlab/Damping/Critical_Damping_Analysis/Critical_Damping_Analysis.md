# Critical_Damping_Analysis

This project sweeps suspension spring stiffness and calculates:

- Natural frequency
- Critical damping

## Files

- `Critical_Damping_Analysis.m`: main MATLAB script.
- `data.csv`: parameters for this script only.
- `load_data.m`: CSV loader.

Run `Critical_Damping_Analysis.m` in MATLAB. Parameters can be changed from `data.csv`.
